# VoiceCanvas backgrounds

Backgrounds that the Voice Canvas app offers under **Samples → ＋ More**. The app reads
`catalog.json` from this repository and downloads the files it lists:

    https://raw.githubusercontent.com/khalidalmannai/VoiceCanvas-backgrounds/main/catalog.json

The repository must be **public** (the app downloads without signing in).

## Add a background

1. Upload the file to `photos/` (JPEG, portrait, about 1080×1920) or `videos/` (MP4, H.264,
   portrait 720×1280 or 1080×1920, a few seconds that loop smoothly, no sound needed).
2. Upload a small preview image to `thumbs/` (JPEG, about 270×480).
3. Add an entry to `catalog.json`:

```json
{
  "id": "city-lights",
  "name": "City lights",
  "type": "video",
  "file": "videos/city-lights.mp4",
  "thumb": "thumbs/city-lights.jpg",
  "duration": 10,
  "bytes": 2400000,
  "pro": true
}
```

| Field | Meaning |
|---|---|
| `id` | Lowercase letters, digits and `-` only. **Never change it** once published (the app uses it to know what is already downloaded). |
| `name` | Shown in the app. |
| `type` | `photo` or `video`. |
| `file`, `thumb` | Paths inside this repository (letters, digits, `_ . / -`). |
| `bytes` | File size, for the size shown in the list (optional). |
| `duration` | Video length in seconds (optional, shown in the list). |
| `pro` | `true` = Pro only (default), `false` = free for everyone. |

Changes appear in the app right away (GitHub may cache files for a few minutes). No app
update is needed. Files larger than 300 MB are ignored by the app.

Only upload images and videos you have the rights to share. The starting set here was
generated by code for this project and is free to use.
